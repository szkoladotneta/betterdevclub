Program warsztatu

Copilot który naprawdę działa

3h live (21:00–00:00), hands-on, na prawdziwym projekcie .NET. Prowadzą Kajetan i Piotr Stapp — dwóch Microsoft MVP, każdy ze swoim kawałkiem produkcyjnego workflow. Nie ktoś, kto przygotował prezentację, żeby o tym mówić.

1

Fundament — Copilot który zna Twój projekt — Kajetan

50 minut · copilot-instructions.md
  • Dlaczego Copilot generuje AI slop — jak "widzi" projekt i gdzie traci kontekst
  • Live: ten sam prompt bez instrukcji vs. z instrukcjami → widoczna różnica jakości kodu
  • copilot-instructions.md — stack, konwencje, co zawsze robić, czego nigdy: piszemy razem krok po kroku
  • Long-term memory agentów — agent-decisions.md: logujesz korekty planów agentów → Copilot uczy się Twojego projektu z każdą iteracją
2

Multi-agent workflow programistyczny — Kajetan

50 minut · 5 agentów + HITL
  • Dlaczego single-agent nie wystarczy — analogia do ról w zespole (architekt ≠ QA ≠ reviewer)
  • Pipeline 5 agentów — planner, implementer, verifier, code-reviewer, pr-commit — z obowiązkowymi HITL checkpointami
  • HITL (Human in the Loop) — 2 obowiązkowe checkpointy: po planner i po code-reviewer. Orkiestrator nie decyduje za Ciebie.
  • Live end-to-end: dodanie endpointu z walidacją — cały pipeline na prawdziwym projekcie
  • Konfiguracja agentów w .github/agents/ — scope limiting, max iterations guard, gotowe szablony do repo
3

Praca produkcyjna — Refactoring, code review, CI/CD — Piotr Stapp

35 minut · DevOps workflow
  • Bezpieczny refactoring legacy kodu — copilot-instructions.md + prompt file /refactor = wynik zgodny z architekturą projektu
  • Checklista code review dla kodu AI: null safety, wycieki IDisposable, side effects, brak testów happy-path only
  • Live: generowanie dotnet-ci.yml (build, test, publish) z Copilotem — jak promptować YAML bez halucynacji
4

Q&A live — Kajetan & Piotr

25 minut · wspólne Q&A
  • Pytania z całego wieczoru — priorytetyzujemy najczęstsze z Zoom chat
  • "Mam projekt X, czy to zadziała?" — odpowiedzi na konkretne przypadki z audiencji
  • 3 rzeczy do wdrożenia w ciągu 48h po warsztacie — konkretny plan, nie lista "do nauki"
Po warsztacie masz
  • copilot-instructions.md — szablon .NET dopasowany do Twojego projektu, gotowy do wdrożenia od jutra
  • 5 gotowych agentów — planner, verifier (deterministyczny!), code-reviewer, implementer, pr-commit — konfiguracje do podpięcia pod własne repo
  • agent-decisions.md — szablon long-term memory: Twój Copilot uczy się z każdego projektu, a nie zaczyna od zera
  • dotnet-ci.yml + ArchitectureTests.cs — pipeline CI/CD i guardrail architektoniczny, które pilnują kodu agentów
  • Pewność — wiesz gdzie kończy się agent, zaczyna człowiek — i jak skonfigurować HITL żeby AI slop nie lądował w produkcji
